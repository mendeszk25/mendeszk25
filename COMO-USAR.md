# Como usar

1. No GitHub, crie (ou abra) o repositório público chamado exatamente `mendeszk25`.
2. Copie `README.md` e a pasta `assets/` para a raiz desse repositório.
3. Faça commit e push.
4. O GitHub exibirá esse README automaticamente no seu perfil.

A coluna esquerda da referência (avatar, bio, followers, localização e achievements)
é a interface nativa do GitHub e deve ser configurada em Edit profile.
